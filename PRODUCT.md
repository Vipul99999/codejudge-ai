# Product

CodeJudge AI simulates professional AI evaluation and code-quality workflows used by trainers, prompt engineers, code evaluators, and LLM benchmarking teams.

## Core Jobs

- Evaluate code readability, maintainability, complexity, naming, smells, and edge-case coverage.
- Detect likely bug risks such as null errors, boundary issues, recursion hazards, infinite loops, race conditions, memory risks, and async mistakes.
- Generate normal, edge, corner, and stress test cases with exportable JSON and CSV.
- Estimate time and space complexity with confidence values.
- Compare two solutions and identify the stronger submission.
- Evaluate AI-generated code responses for instruction following, correctness, reasoning, hallucination risk, code quality, and safety.
- Review step-by-step reasoning for logic quality, assumptions, contradictions, and gaps.
- Generate evaluation datasets for AI training workflows.
- Score weighted rubrics and track benchmark metrics locally.

## Product Principles

- Professional evaluator console first; no marketing-first landing page.
- Deterministic and explainable outputs.
- No arbitrary code execution.
- Confidence and limitations are visible in every evaluator response.
- Export workflows are built into dataset and test-case features.
