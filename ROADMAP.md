# Roadmap

## Near Term

- Persist benchmark events to SQLite or Postgres.
- Add richer Python AST rules for data-flow and exception paths.
- Add tree-sitter parsing for JavaScript, TypeScript, Java, and C++.
- Add evaluator report templates for common AI-training rubrics.
- Add authenticated workspaces and saved evaluation projects.

## Medium Term

- Dataset versioning and diff views.
- Batch import for prompt-response evaluation.
- Advanced rubric editor with drag-and-drop weights.
- Organization-level benchmark dashboards.
- Exportable PDF evaluation reports.

## Long Term

- Plugin-based analyzer rule packs.
- Human review queues for evaluator teams.
- Model comparison dashboards using externally supplied outputs.
- CI integration for static code-quality evaluation.
